# Tangga Pintar

Game ular tangga edukasi untuk SD dengan peran siswa dan guru.

## Jalankan dengan Node.js

1. Impor `schema.sql` ke MySQL.
2. Salin `.env.example` menjadi `.env` lalu isi nilainya.
3. Jalankan `npm install` lalu `npm start` dan buka http://localhost:3000

## Catatan keamanan

Jangan pernah mengunggah `config.php` atau `.env` ke GitHub. Keduanya sudah ada di `.gitignore`.
